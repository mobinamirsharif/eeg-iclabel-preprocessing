# DEAP Data Access Note

## Dataset

DEAP — Database for Emotion Analysis using Physiological Signals

## Data used in this repository

Distributed preprocessed Python files (`data_preprocessed_python`)

## Original data required for further validation

Original BioSemi/BDF recordings

## Access status

The original recordings were not available to the author during this study.

## Actions taken

- Checked the official DEAP access resources.
- Attempted to obtain the original recordings through the official route.
- Contacted the dataset authors requesting access or guidance.
- No response had been received when this access note was prepared.

No attempt was made to obtain or redistribute DEAP data through unauthorized or unofficial sources.

Consequently, this repository does not claim to characterize ICLabel behavior on the original raw DEAP recordings. If access becomes available in the future, a raw-data replication would be the appropriate next validation step.
