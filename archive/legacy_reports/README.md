# Legacy reports — superseded conclusions

> **Historical-use warning:** The files in this directory contain conclusions and terminology that have been superseded. They must not be cited, summarized, or presented as the repository's current scientific findings. Use `reports/final_findings.md`, `reports/troubleshooting.md`, and `docs/methodology.md` for the current evidence-aware interpretation.

These PDFs are unmodified historical snapshots. They are retained so the development record is complete, but they are not the current scientific conclusion of the repository.

- `legacy_deap_initial_report.pdf`: initial 32-subject DEAP report. Its physiological explanation for the high Heart Beat output was later rejected.
- `legacy_deap_multistage_report.pdf`: V1-V4 troubleshooting narrative and the correct stage-level counts, alongside causal statements that remain unproven.
- `legacy_engineering_troubleshooting_report.pdf`: environment and implementation log. Claims of verified ECG removal, GPU execution, and definitive automatic cleaning are superseded.
- `legacy_bci_final_model_report.pdf`: nine-subject BCI report. Its dashboard omitted Channel Noise and Other from a 122-component denominator while the reconciled total is 135; "pure brain," "removed artifact," and definitive spectral-collapse language are superseded.

The three `legacy_*.html` files are also unmodified Baseline-era technical, comprehensive, and troubleshooting reports. They contain the same historical framing and are retained for provenance rather than current guidance.

Read `reports/final_findings.md`, `reports/troubleshooting.md`, and `docs/methodology.md` for the corrected interpretation. Review the DEAP license and the scientific conclusions with the project supervisor before making this private repository public.

For a public release, the recommended approach is to keep these reports out of the main release and, if their historical value justifies publication, place them in a clearly labelled historical release after supervisor and DEAP-license review. They should otherwise remain in the private project archive. No report has been deleted or modified.
